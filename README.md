## What is this 
this is a diy flipper 0 which i tried to make it has 7 buttons and a screen it works on a esp32 mini.

## why it exists
i was quite amazed by the flipper 0 like how it can change the traffic lights and steal any rfid connections so i was amazed by its powers so i thought lets try to make this i thought i will watch like how it works but studying is quite boring.
